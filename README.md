# QuickDine

QuickDine is a MERN stack restaurant booking platform.

## Features

- User authentication
- Restaurant management
- Restaurant booking
- Owner dashboard
- Image upload using Cloudinary

## Tech Stack

Frontend:
- React
- TypeScript
- Tailwind CSS

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose

## Setup

1. Clone repository
2. Install dependencies
3. Add environment variables
4. Run server
